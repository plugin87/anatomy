# Motion: ทำให้มีชีวิตแบบสงบ

## หลัก
- **อิงเวลา ไม่อิงเฟรม** ทุกการขยับต้องใช้ `dt` (ถูก clamp ไว้ที่ 1/30) เพื่อให้ผลเหมือนกันทุกเครื่อง และให้ `#t=` กรอเวลาได้แบบ deterministic
- **ฟิสิกส์จริงเมื่อมีความหมาย** ของที่ตกใช้แรงโน้มถ่วง (`v += G*dt`) ของที่ไถลใช้แรงเสียดทานคงที่ ซึ่งคำนวณ decel ได้จากระยะหยุด `v0² / 2d` ส่วนการตามเป้าใช้ `follow(from, to, dt, tau)` โดย tau อยู่ราว 0.05–0.3 วินาที
- **easing ของ stroke** ใช้ `1 - (1-t)^3` ขาออกเร็วและขากลับนุ่ม
- **เขียนลง attribute โดยตรง** ใช้ `el.setAttribute("transform", along([dx, dy, dz]))` และห้าม rebuild innerHTML ทุกเฟรม
- **ลำดับ DOM คือลำดับความลึก** ใช้ `setOrder(parent, els)` ซึ่งจะ append ใหม่เฉพาะเมื่อลำดับเปลี่ยน
- **Pool** ชิ้นที่เกิดและหายบ่อย เช่น เหรียญ ให้สร้างไว้ล่วงหน้าแล้ว `take()` / `give()` ห้ามสร้าง element ใหม่ระหว่างที่เล่นอยู่

## Idle tour
- เริ่มทันทีเมื่อเปิดหน้า และกลับมาเล่นต่อหลังจากไม่มีใครแตะ 5 วินาที
- **ต้องไปถึงกรณีสำคัญ** ให้คำนวณจากโมเดลว่าต้องใช้จังหวะเท่าไรถึงจะไปถึงสถานะขอบ (ว่าง, เต็ม, ชน) แล้วเขียนเหตุผลเป็นคอมเมนต์ไว้
- มีช่วงพักให้ระบบฟื้นตัว (refill) เพื่อให้เห็นวงจรครบ

## Input
- `pointerdown` บน stage ต้อง `preventDefault` และ focus stage
- คีย์บอร์ด: Space/Enter สำหรับ action หลัก และลูกศรสำหรับปรับค่า ต้องเขียนไว้ใน hint ทั้งหมด
- `aria-valuetext` บน stage และ `aria-live="polite"` บน readout (มีใน `cardHtml` อยู่แล้ว)

## Reduced motion
`tick(dt, still)`: เมื่อ `still` เป็นจริง ทุกอย่างต้องกระโดดไปที่ปลายทางทันที ไม่มีทัวร์ และยังโต้ตอบได้ตามปกติ

## ความจริงระหว่างเคลื่อนไหว
ถ้าโมเดลตัดสินผลไปแล้วแต่ภาพยังตามไม่ทัน (เช่น token ถูกนับแล้วแต่เหรียญยังตกอยู่) ให้กลไก**รอ** ห้ามให้ภาพโกหก ตัวอย่างเช่น ตัวดันจะไม่ทำงานถ้า `tokens >= 1` แต่ในแท่นยังไม่มีเหรียญ
