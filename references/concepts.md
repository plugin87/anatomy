# แนวคิด → วัตถุ

ประโยคทดสอบ: "**อะไร**ขยับ และการขยับนั้น**หมายถึง**อะไร" ถ้าตอบได้ในประโยคเดียว แสดงว่าเลือกวัตถุถูก

| แนวคิด | วัตถุ | อะไรขยับ = หมายถึงอะไร |
|---|---|---|
| Token bucket rate limit | เครื่องจ่ายเหรียญ: ท่อป้อนเหรียญ, แท่นวางเหรียญ, ตัวดัน (ตัวอย่างที่มีมาให้) | เหรียญตกลงมา = refill, ตัวดันดันเหรียญล่างสุดออก = request ที่ได้ token, ดันแล้วว่าง = 429 |
| Leaky bucket | กรวยมีวาล์วเข็ม หยดลงถ้วยตวง | น้ำหยดด้วยอัตราคงที่ = อัตราที่ออก, น้ำล้นขอบ = drop |
| Cache hit / miss | กุญแจแบบ pin-tumbler | หมุดเรียงตรงแนวทุกตัว = hit จึงหมุนได้ทันที, ไม่ตรง = miss ต้องไปเจียรกุญแจใหม่ |
| Hash map + collision | ตู้ลิ้นชักไปรษณีย์ที่มีเครื่องคัดแยก | การ์ดตกลงช่องตาม hash, ช่องเดียวกันซ้อนกัน = chain |
| Bloom filter | แผงสวิตช์โยก k ตัวต่อหนึ่งคีย์ | ทุกตัวที่ตรวจโยกขึ้นอยู่ = "อาจมี", มีตัวใดตัวหนึ่งลง = "ไม่มีแน่" |
| Mutex / lock | ประตูกั้นแบบหมุน (turnstile) กับโทเคนทองเหลือง | มีคนผ่านได้ทีละคน, คนที่เหลือรอคิว |
| Semaphore (n) | ราวแขวนกุญแจ n ดอก | หยิบกุญแจออก = acquire, ราวว่าง = ต้องรอ |
| Queue / backpressure | สายพานลำเลียงที่มีสวิตช์ความยาวคิว | กล่องสะสมจนถึงเซนเซอร์ = สายพานต้นทางหยุด |
| Debounce | สวิตช์หน่วงเวลาแบบโช้คน้ำมัน (dashpot) (ตัวอย่างที่มีมาให้) | ฝาลอยขึ้นด้วยความเร็วคงที่ใช้เวลา `wait` พอดี ถ้ากดซ้ำฝาจะถูกดันลงใหม่ ถ้าถึงยอดสวิตช์จะปิด = fire |
| Throttle | กลไกเฟือง escapement ของนาฬิกา | ปล่อยครั้งเดียวต่อหนึ่งจังหวะ ไม่ว่าจะดันแรงแค่ไหน |
| TCP handshake | ระบบรอกส่งของระหว่างสองหอคอย | SYN, SYN-ACK, ACK เป็นตะกร้าสามเที่ยว |
| Load balancer (round robin) | เครื่องแจกไพ่หมุน | หัวจ่ายหมุนไปทีละช่อง |
| Consistent hashing | วงแหวนหมุนที่มีหมุด server | คีย์ไหลตามเข็มไปยังหมุดถัดไป, ถอดหมุดออกแล้วย้ายแค่ช่วงเดียว |
| Garbage collection (mark-sweep) | ตะแกรงร่อนที่มีแม่เหล็ก | ชิ้นที่ยังเกาะ root ถูกดูดค้างไว้ ที่เหลือร่วงลง |
| Git branch / merge | รางรถไฟที่มีประแจสับราง | รถแยกออกแล้วกลับมาบรรจบ |
| Exponential backoff | ลูกตุ้มที่แกว่งช่วงยาวขึ้นเรื่อยๆ | ระยะรอแต่ละรอบยาวขึ้นเป็นสองเท่า |
| Temperature sampling | ตู้สล็อตที่มีลูกเหล็ก (Galton board) ปรับความชันได้ | ความชันต่ำ = ลูกเหล็กกระจาย = temperature สูง |
| Separable blur | ตรายางตะปู 49×49 เทียบกับหวีสองอันบนราง | งาน 2 มิติแยกเป็น 1 มิติสองรอบ |

## วิธีคิดวัตถุใหม่

1. เขียนแนวคิดเป็นคำกริยา เช่น เติม, หยิบ, ปฏิเสธ, รอ, ล้น
2. หาเครื่องในโลกจริงที่ทำกริยาเหล่านั้นด้วยแรงหรือกลไก เช่น แรงโน้มถ่วง สปริง เฟือง หรือวาล์ว
3. นับให้ตรง: ตัวเลขในแนวคิด เช่น capacity หรือ rate ต้องเป็นจำนวนชิ้นหรือระยะจริงในวัตถุ
4. หาสถานะขอบ เช่น ว่าง เต็ม หรือชนกัน แล้วตรวจว่าวัตถุแสดงสถานะนั้นด้วยกลไกได้ เช่น ตัวดันดันโดนแต่อากาศ
5. ถ้าต้องติดป้ายเพื่อให้เข้าใจ แปลว่าวัตถุยังไม่ใช่ ให้กลับไปข้อ 2
