# Craft: หน้าตาของ figure

## 1. โทนและ tokens

| บทบาท | solid `tone` | เส้น |
|---|---|---|
| ฐาน, ขา, ป้าย | `lo` / `mid` | ร่อง `lo` |
| โครงสร้าง: เสา, ราง, แขน | `mid` | ตะเข็บ `faint` |
| กลไกที่ผู้อ่านต้องเห็นว่าขยับ | `hi` | — |
| **subject** (ชนิดเดียว) | `lit: true` | ขอบเป็น `lit` (สีขาวในธีมมืด, สีดำในธีมสว่าง) |
| ขีดย่อย / ขีดหลัก / ขีดศูนย์ | — | `lo` / `mid` / `hi` |

สีทุกค่าเป็น CSS tokens `--ix-*` ใน `kit/iso.mjs` ถ้าจะเปลี่ยน brand ให้แก้ที่ `DARK` และ `LIGHT` เท่านั้น ห้ามใส่ hex ลงใน drawing (`check.mjs` จะ fail)

## 2. คลังชิ้นส่วน (สูตร)

```js
// ฐานบนขา 4 ข้าง: เงา → ขา (เรียงตามความลึก) → แผ่น → ร่อง → สกรู
out.push(k.haloSvg(k.haloOf(k.insetPlan(PLATE, -2), -H - FOOT, P), 10));
for (const [x, y] of k.byDepth(k.corners(PLATE, 18), P, ([x, y]) => [x, y, 0])) {
  out.push(S(k.cylinder(x, y, 7, -H - FOOT, 1.6, P, 28), { tone: "lo" }));        // แป้นยาง
  out.push(S(k.cylinder(x, y, 5.4, -H - FOOT + 1.6, FOOT - 1.6, P, 28), { tone: "mid" }));
}
out.push(S(k.slab(PLATE, -H, H, P, 8), { tone: "mid" }));
out.push(L(k.planOutline(k.insetPlan(PLATE, 5), 0, P), { tone: "lo" }));          // ร่องรอบขอบ
const screws = k.corners(PLATE, 9.5);
out.push(L(screws.map(([x, y]) => k.ring(x, y, 2.2, 0, P, 16)).join(""), { tone: "lo" }));
out.push(D(screws.map(([x, y]) => k.iso([x, y, 0], P)), { r: 0.5 }));

// ปุ่มหมุนมีลาย + ตัวชี้
S(k.cylinder(cx, cy, r, z, h, P, 32), { tone: "mid" });
L(k.knurl(cx, cy, r, z + 0.6, z + h - 0.6, 22, P), { tone: "lo" });

// สเกลบนแถบ: ขีดห้อยจากขอบแถบ
const t = k.ticks(from, to, 3, 4, edgeY, z, [1.6, 3], P);
L(t.minor, { tone: "lo" }); L(t.major, { tone: "mid" });

// สเกลบนหน้าตั้ง (หน้าที่หันไปทาง +x)
k.faceTicks(faceX, edgeY, levels, 4, [-1.6, -3.2], P);

// ป้ายชื่อ: แผ่นบาง + rule line 3 เส้น (free) + ป้ายสลักได้หนึ่งจุด
S(k.slab(label, 0, 0.7, P, 3), { tone: "lo", crease: "none" });
L(k.onPlane([[x0, y], [x0 + len, y]], 0.7, P), { tone: "faint", free: true });
k.faceText(k.topMatrix([x, y], 0.7, P, "x"), "8", { size: 5.5, tone: "mid" });

// เหรียญ / แผ่นกลม: ขอบมีลาย reeding, ร่องหน้า, รูกลาง
S(k.cylinder(0, 0, R, 0, H, P, 56), { lit: true, crease: "lo" });
L(k.knurl(0, 0, R, 0.7, H - 0.7, 40, P), { tone: "lo" });
```

คำศัพท์ชิ้นส่วนที่ทำให้งานดู "จริง": แผ่นฐาน, ขายาง, ร่องขอบ, สกรูมุม, ป้ายรุ่น, แถบสเกล, เสาไกด์, ปลอกรองเสา (collar), หมวกเสา, ราง, ตัวกั้นปลายราง, แคร่, บูช, สปริง, ตัวดัน, แท็บนิ้ว, แขน, วงแหวนรัด (clamp band) พร้อมสกรู 2 ตัว, ฝาเกลียวมีลาย, ประตูเลื่อน (gate), ปุ่มหมุนพร้อม detent

## 3. Painter's order

กฎ: **หลังไปหน้า ล่างขึ้นบน** โดย "หน้า" คือ `depthOf` ที่มากกว่า (ผู้ชมอยู่ทาง +x +y และอยู่ด้านบน)

- ชิ้นที่ซ้ำกัน เช่น ขา สกรู หรือเสา ให้เรียงด้วย `k.byDepth`
- **ทรงกระบอกที่มีวงแหวนรัด**: วาดท่อช่วงล่าง → วงแหวน → ท่อช่วงบน ห้ามวาดท่อยาวทั้งท่อก่อนวงแหวน
- **ชิ้นที่ห่อรอบชิ้นอื่น** เช่น สปริงรอบแกน หรือเสา 2 ต้นรอบกองเหรียญ: ของด้านหลังวาดก่อน subject แล้วของด้านหน้าวาดทีหลัง
- **ของที่ลอดผ่าน** เช่น แกนที่ทะลุแผ่นกลางกอง: แยกส่วนที่อยู่เหนือชิ้นบนสุดออกมาเป็นอีกชิ้น หรือเปลี่ยนการออกแบบให้ไม่มีแกนทะลุ (ตัวอย่างใช้เสาไกด์แทนแกนกลาง)
- **ชิ้นที่ขยับข้ามความลึก**: แบ่งเป็นหลาย layer แล้วย้าย element ข้าม layer ตามตำแหน่งจริง ตัวอย่างนี้ใช้ `eject`, `stack` และ `high`
- **วิธีพิสูจน์ลำดับของคู่หนึ่ง**: ลากรังสีจากจุดบนชิ้น A ไปหาผู้ชม ซึ่งในแปลนคือทิศ (cos az, sin az) และในแนวตั้งจะยกขึ้น tan(el) ต่อหนึ่งหน่วยแปลน ถ้ารังสีชนชิ้น B แปลว่า B อยู่หน้า A ให้เขียนเหตุผลนี้เป็นคอมเมนต์ไว้ใน build

## 4. Anti-patterns ที่ทำให้งานถูกตีกลับ

- กล่องติดป้าย, ลูกศรลอย, เส้นบอกขนาด
- แผ่นใหญ่โล่งๆ ที่ไม่มีร่อง สกรู หรือตะเข็บ
- เส้นที่หยุดกลางหน้าโดยไม่มีเหตุผล (ยกเว้นที่มาร์กไว้ว่า `free`)
- lit มากกว่าหนึ่งชนิดชิ้นส่วน ทำให้ผู้อ่านไม่รู้ว่าต้องดูตรงไหน
- ข้อความอธิบายในภาพวาด ข้อความแบบนี้ต้องย้ายไปไว้ใน caption ใต้การ์ด
- readout ที่แต่งขึ้นเองหรือไม่ได้คำนวณจากโมเดล
